# 🌌 Solar System Exploration

An interactive, educational website dedicated to exploring our Solar System, its planets, and other celestial objects.

Built as a personal web development project to explore the possibilities of **HTML, CSS, and JavaScript** while learning frontend development.

## 🚀 About the Project

Solar System Exploration started as a basic HTML webpage and gradually evolved into a more developed, visually engaging website.

The project aims to make learning about our Solar System more interesting through an accessible interface, visual elements, and interactive features.

It also represents my progress as a beginner in web development, from writing basic HTML to experimenting with styling and JavaScript functionality.

## ✨ Features

- Educational content about the Solar System.
- Visually organised sections for exploring celestial objects.
- Styled layouts and visual elements using CSS.
- Interactive functionality using JavaScript.
- Responsive design elements for different screen sizes.

## 🛠️ Technologies Used

- **HTML5** – Page structure and content.
- **CSS3** – Styling, layouts, and visual presentation.
- **JavaScript** – Interactive functionality.

## 🤖 AI-Assisted Development

AI tools were used during the development process to help expand the original implementation, improve the presentation, and explore additional frontend functionality.
